Site designs

20 full designs of frogscooper.dev, built from one copy of the content by _designs/build.py. Nothing in _designs/ is published. To put one live, run python3 _designs/switch.py 03 (or any number), check it, and commit. python3 _designs/switch.py original restores the old site.

01Moirétop band

Two fine line gratings laid over each other at a slight angle; slow bands appear where they drift in and out of step.

Each project tilts the second grating by a different angle. 02Cyanotypepinned left

A sun print on blueprint paper: plant forms in white on Prussian blue, swaying slightly.

Each project grows a different number of stems. 03Star trailsfull screen

A camera left open all night. Stars wheel around the pole and draw arcs.

Each project moves the pole to a different point in the sky. 04Chladnifull screen

Sand on a vibrating plate gathers on the lines that stay still, and the plate drifts toward its next note.

Each project is a vibration mode, a pair of whole numbers. 05Phyllotaxispinned left

Seeds placed 137.5° apart, the way a sunflower packs its head. The spiral turns very slowly.

Each project turns its seeds by a slightly different angle; only 137.5° packs them evenly. 06Risotop band

A two-colour risograph print in pink and blue. Halftone dots overlap where the inks meet.

Each project is a new print with its own sun and horizon. 07Phosphorfull screen

An oscilloscope in amber. Two waves at different speeds draw one closed figure that slowly turns.

Each project is a frequency ratio. 08Glasspinned left

Stained glass from a Voronoi diagram: each pane is the ground closest to one drifting seed.

Each project adds more seeds, so its glass gets finer. 09Ridgelinestop band

Mountain ridges fading into dusk haze. The nearer the ridge, the darker it is.

Each project brings a different ridge forward. 10Filingsfull screen

Iron filings on paper, lined up along the field between magnetic poles.

Each project sets out its poles differently. 11Surveymounted sheet

A survey sheet: contour lines over a lake, with every fifth line inked heavier. The water rises very slowly and the contours creep uphill.

Each project is a different sheet of the same country. 12Ebrumounted sheet

Turkish paper marbling. Drops of ink float as stones, then a stylus and combs draw through them.

Each project is a traditional pattern: battal, gel-git, taraklı, şal, bülbül yuvası. 13Loomtop band

A loom, one cell per thread crossing. Cloth is woven at the fell line and wound upward; the bare warp hangs below.

Each project is a different weave draft, from goose-eye twill to houndstooth. 14Poolfull screen

Sunlight through moving water, focused into bright nets on the tiles of a pool floor.

Each project is a pool of a different depth. 15Aurorafull screen

Curtains of aurora over a ridge at night, green at the hem and violet higher up.

Each project is a geomagnetic storm level; the higher the Kp, the lower and brighter the curtains. 16Physarumpinned right

The slime mould from the slime studies, live: thousands of agents lay and follow a trail, and a network grows between the food.

Each project feeds it a different number of food sources and changes how wide it senses. 17Herbariumpinned left

A herbarium sheet: a pressed plant drawn in sepia ink, taped down at the stem. Its tips stir as if in a draught.

Each project is a different plant, grown from its own L-system. 18Orrerypinned right

A brass orrery on a star chart. A chord is drawn between two planets as they go round, and over a full cycle it traces a rose.

Each project is an orbital resonance. Home is 8:13, the pentagram of Earth and Venus. 19Zelligetop band

Glazed tilework from a quasicrystal: plane waves at evenly spaced angles, summed. The pattern never repeats.

Each project has a different order of symmetry. 20Rainfull screen

Rain on a pond at night. Each drop sends out rings, flattened by the low angle, and the rings cross.

Each project is a heavier or lighter shower. 21Bilicreator profile
