Site designs

Ten full designs of frogscooper.dev, built from one copy of the content by _designs/build.py. Nothing in _designs/ is published. To put one live, run python3 _designs/switch.py 03 (or any number), check it, and commit. python3 _designs/switch.py original restores the old site.

01Moirétop layout

Two fine line gratings laid over each other at a slight angle; slow bands appear where they drift in and out of step.

Each project tilts the second grating by a different angle. 02Cyanotypeleft layout

A sun print on blueprint paper: plant forms in white on Prussian blue, swaying slightly.

Each project grows a different number of stems. 03Star trailsfull layout

A camera left open all night. Stars wheel around the pole and draw arcs.

Each project moves the pole to a different point in the sky. 04Chladnifull layout

Sand on a vibrating plate gathers on the lines that stay still, and the plate drifts toward its next note.

Each project is a vibration mode, a pair of whole numbers. 05Phyllotaxisleft layout

Seeds placed 137.5° apart, the way a sunflower packs its head. The spiral turns very slowly.

Each project turns its seeds by a slightly different angle; only 137.5° packs them evenly. 06Risotop layout

A two-colour risograph print in pink and blue. Halftone dots overlap where the inks meet.

Each project is a new print with its own sun and horizon. 07Phosphorfull layout

An oscilloscope in amber. Two waves at different speeds draw one closed figure that slowly turns.

Each project is a frequency ratio. 08Glassleft layout

Stained glass from a Voronoi diagram: each pane is the ground closest to one drifting seed.

Each project adds more seeds, so its glass gets finer. 09Ridgelinestop layout

Mountain ridges fading into dusk haze. The nearer the ridge, the darker it is.

Each project brings a different ridge forward. 10Filingsfull layout

Iron filings on paper, lined up along the field between magnetic poles.

Each project sets out its poles differently.
