04

once

Python · 2026

A small Python library that makes side-effecting tool calls safe for AI agents to retry. Each call gets an idempotency key stored in SQLite, so a retried "charge the card" or "send the email" returns the saved result instead of running twice. No dependencies.

fly-osu

In progress

An experiment using the reconstructed male fruit fly CNS as a controller for osu!. I’m building a connectome simulator that encodes beatmap and game-state information into neural input, then decodes network activity into cursor movement and click timing.
