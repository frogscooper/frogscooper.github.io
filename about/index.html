What I build

Lilypad is a free file converter and a set of image, PDF, and utility tools. Conversions run in the browser. Files are never uploaded. The homepage lists every tool.

once is a Python library, published on PyPI as agent-once. It makes a side-effecting tool call safe for an AI agent to retry. A second attempt returns the saved result instead of running the effect again.

Other work is on the homepage: a BSP dungeon generator, slime-mould studies, open source pull requests, and a few experiments still in progress. The code is on GitHub.
